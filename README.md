# sapinails.il

האתר של הסטודיו של ספיר, על GitHub Pages.

- `book/` דף קביעת תורים ללקוחות. מציג רק שעות פנויות. לקוחה חדשה ממתינה לאישור של ספיר, ולקוחה מוכרת (לפי הטלפון) מקבלת אישור מיד.
- `admin/` מסך הניהול של ספיר, עם סיסמה: יומן, אישור בקשות, תזכורות למחר, כרטיסיות מועדון, שעות פעילות וחסימות, נוסחי הודעות והתראות לטלפון. אפשר להוסיף אותו למסך הבית כמו אפליקציה.
- `k/{גודל הכרטיסייה}/{מספר הניקובים}/` דפי כרטיסיית המועדון שהלקוחות מקבלות בוואטסאפ. התמונה שוואטסאפ מציג נמצאת ב־`og/`.
- `supabase/schema.sql` מבנה מסד הנתונים והכללים (Supabase). רק המשתמשת שרשומה בטבלה `admins` יכולה לקרוא ולשנות נתונים, ולקוחות יכולות רק לבקש תור. תור מאושר פותח ללקוחה כרטיסיית מועדון אוטומטית. שינויים שמריצים פעם אחת על מסד קיים נמצאים ב־`supabase/migrations/`.
- `supabase/functions/notify/` פונקציית השרת ששולחת לטלפון של ספיר התראה על כל תור חדש מהאתר, ובערב את רשימת התורים של מחר. נפרסת ב-Supabase עם «Verify JWT» כבוי (היא בודקת כל בקשה בעצמה) ולא צריכה סודות שמדביקים ידנית.
- `assets/config.js` כתובת הפרויקט במסד הנתונים והמפתח הציבורי שלו.

את דפי הכרטיסייה ואת התמונות בונים מחדש עם הסקריפט `build_cards.py` ששמור בפרויקט של ספיר ב-Claude.
