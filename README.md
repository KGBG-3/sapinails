# sapinails.il

האתר של הסטודיו של ספיר, על GitHub Pages.

- `book/` דף קביעת תורים ללקוחות. מציג רק שעות פנויות. לקוחה חדשה ממתינה לאישור של ספיר, ולקוחה מוכרת (לפי הטלפון) מקבלת אישור מיד.
- `admin/` מסך הניהול של ספיר, עם סיסמה: יומן, אישור בקשות, כרטיסיות מועדון, שעות פעילות והגדרות.
- `k/{גודל הכרטיסייה}/{מספר הניקובים}/` דפי כרטיסיית המועדון שהלקוחות מקבלות בוואטסאפ. התמונה שוואטסאפ מציג נמצאת ב־`og/`.
- `supabase/schema.sql` מבנה מסד הנתונים והכללים (Supabase). רק המשתמשת שרשומה בטבלה `admins` יכולה לקרוא ולשנות נתונים, ולקוחות יכולות רק לבקש תור.
- `assets/config.js` כתובת הפרויקט במסד הנתונים והמפתח הציבורי שלו.

את דפי הכרטיסייה ואת התמונות בונים מחדש עם הסקריפט `build_cards.py` ששמור בפרויקט של ספיר ב-Claude.
