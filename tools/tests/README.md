# בדיקות

הסקריפטים כאן בודקים את האתר ואת מסך הניהול בדפדפן אמיתי (Chromium), בלי לגעת במסד הנתונים האמיתי:
כל קריאה של הדפים למערכת התורים נענית מקומית, עם לקוחות ותורים מומצאים.

פעם אחת, בתיקייה הזו: `npm install axe-core` (בודק הנגישות). צריך גם Python עם Playwright ו-Chromium.

מריצים מתיקיית השורש של המאגר, אחרי כל שינוי ולפני העלאה:

    python3 tools/tests/check_public.py         # כל הדפים הציבוריים בארבעה רוחבי מסך
    python3 tools/tests/check_admin_flows.py    # מסך הניהול: יומן, סיום טיפול, לקוחה חדשה, מתנה, חיפוש, מחיקה
    python3 tools/tests/check_admin_marks.py    # מסך הניהול: הסימון «לא לשלוח הזמנות»

כל סקריפט מסתיים ב-`PROBLEMS: 0` או ב-`ALL PASSED` כשהכול תקין.

- `harness.py` שרת מקומי לקובצי האתר, מערכת תורים מדומה לדפים הציבוריים, והרצת axe.
- `admin_harness.py` מסד נתונים מדומה למסך הניהול (כניסה, לקוחות, הגדרות, תורים, עדכונים חיים).
